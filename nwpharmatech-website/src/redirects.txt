# Cloudflare Pages redirects (build.py validates these and writes public/_redirects). Route map: docs/url-map.md
#
# Page URLs are extensionless: Cloudflare Pages serves /study from study.html and itself answers
# /study.html and /study/ with a 308 to /study, and /index.html with a 308 to /. Never add a rule for a
# page's own route or those forms: a rule such as "/study /study.html" loops with Cloudflare's 308.
# Every target must be a page route (optionally with a #fragment that exists on that page); a target must not
# itself be redirected; splats (*) and placeholders (:name) are not used, because the build cannot check them.
#
