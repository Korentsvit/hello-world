# Reference and fact verification: NW PharmaTech website

Verified 23 September 2026.

## How this was checked

- **Network:** WebFetch and curl were blocked by the egress proxy (EGRESS_BLOCKED) for every domain tried. That includes jamanetwork.com, psychiatryonline.org, europepmc.org, depts.washington.edu, Companies House (find-and-update.company-information.service.gov.uk) and nwpharmatech.com. curl also failed for nhs.uk, samaritans.org, medicines.org.uk, ema.europa.eu, isrctn.com, nature.com, nejm.org, link.springer.com, api.semanticscholar.org and api.openalex.org.
- **So no item was confirmed from a primary page I fetched myself.** Every "confirmed" value below comes from WebSearch result summaries. These summaries quote or paraphrase the publisher page, PubMed or registry page, or a secondary page. The listed URL is the page the summary came from.
- **Verification levels:**
  - **Search summary (primary-indexed):** the summary came from the publisher, PubMed, a registry or an official page, but I did not open that page.
  - **Search summary (secondary):** the summary came from a secondary site, such as a news site, a blog or another paper.
- **NOT CONFIRMED** means no source returned the value. Nothing below was filled in from memory.
- **Author lists:** Vancouver citations list only the authors that a source returned, then "et al.". The full first-six author lists weren't returned, so complete them before publishing.
- **Before publishing:** someone with normal internet access should open each primary URL (PubMed, journal, NICE, emc, Companies House, CT.gov, ISRCTN) and check the exact figures.
